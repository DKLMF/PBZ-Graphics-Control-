# PBZ-Graphics-Control-
PBZ Graphics Control 是一款 ReShade 插件，它把《影之刃零》大量隐藏的渲染设置整合为一套实时控制面板：Lumen 全局光照、光线追踪 / 路径追踪（ReSTIR + RTXDI）、LOD / 绘制距离、阴影质量以及后期效果，合计约 90 个分组滑块，鼠标悬停可显示提示说明。  插件附带可选的 UE4SS 漏光修复脚本：面板内一键开关，强制所有本地光源正常投射阴影（解决光追 / 路径追踪模式下的漏光问题），修复火光、人物光源异常瑕疵，同时增强 Lumen 全局光照效果。
### 亮点

- 9 个可折叠分类面板，约 90 个实时调节滑块，支持中英双语界面
- 自动保存配置，游戏启动自动加载；每个滑块可实时显示当前是否生效
- 内置版本自检：游戏更新导致内存偏移变更时，插件会安全停用，不会造成游戏崩溃
- 可选 UE4SS 漏光修复（忠实移植自 PhantomShadows），在同一个面板内直接控制

## 主要功能

- **Lumen 漫反射全局光照**：总开关、屏幕探针、辐射缓存、辐射度、SDF 追踪、屏幕追踪
- **Lumen 反射 / SSR 屏幕空间反射**：粗糙度阈值、强度、高光、屏幕空间回退、SSR 质量
- **表面缓存 / 辐射度**：图集尺寸、纹素密度、面片分辨率、反弹密度
- **Lumen 直接光照**：每个瓦片最大光源数量、更新系数
- **光线追踪 / 路径追踪**：光追阴影（点光源 / 矩形光源 / 聚光灯）、环境光遮蔽 AO、反射、全局光照、ReSTIR 间接光照（附带漏光抑制调节项）、RTXDI 直接光照、光追剔除、阴影回退方案
- **绘制距离 / LOD**：视野距离、静态模型 / 植被 LOD、密度、Mip 偏移
- **阴影 / 画质**：阴影分辨率、各向异性、VRS 可变速率着色、sg.* 系列画质等级
- **后期特效**：色调映射、景深 DoF、色差、泛光、运动模糊、体积雾、自动曝光、接触阴影、光束、HDR 输出
- **漏光修复（可选 UE4SS）**：强制本地光源投射阴影，修复火光 / 人物光源瑕疵，增强全局光照

## 依赖要求

- 《影之刃零》Steam 版 **版本号 26367565**（插件依赖固定内存偏移，其他版本会安全跳过，不加载）
- ReShade **6.8.0（开启插件支持）**
- 可选：**UE4SS**（用来启用面板内的漏光修复开关）
